# Consistency / Metadata / Partitioning

## 页面定位

集中讨论访问者观察到的状态、系统记录的索引，以及数据如何分配到分区和节点；将语义与数据归属放在同一框架内理解。

## 核心问题

- 并发读写、覆盖、列举和删除分别需要什么一致性保证？
- 元数据与数据如何关联，更新失败时如何保持可解释的状态？
- 分片、数据放置与热点分别在哪一层处理？
- 扩容和迁移期间，路由、所有权与读写如何协调？

## 后续准备展开的主题

- 线性一致性、最终一致性与读写 / 列举语义的边界。
- 元数据模型、对象索引、版本与数据引用。
- 分区策略、哈希 / 范围分片、放置策略与热点治理。
- 元数据更新与数据写入的原子性边界、失败补偿与垃圾回收。
- 分区拆分、扩容迁移与路由 / 所有权变更。
