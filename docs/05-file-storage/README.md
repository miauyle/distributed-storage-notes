# File Storage

## 页面定位

理解文件、目录与共享命名空间的模型，说明文件语义给分布式实现带来的要求；当前保持类型入口，统一访问模型对照见 [Architecture Map](../01-overview/01-storage-models-architecture-map.md)，按需要再扩展，不表示完整专题已完成。

## 核心问题

- 路径、目录、文件与文件元数据之间是什么关系？
- 文件共享、重命名、锁与缓存如何影响并发访问？
- POSIX 语义与不同网络文件接口的边界如何区分？

## 已有系统案例

[JuiceFS：文件语义、独立元数据与对象后端的组合](../11-typical-storage-systems/06-juicefs.md)展示文件命名空间、数据映射、客户端缓存与对象容量如何合作。重点区分读缓存和待上传写暂存、元数据与正文保护，以及文件提交与应用 Checkpoint 发布；此案例不表示本目录已完成全部文件系统基础正文。
