# File Storage

## 页面定位

理解文件、目录与共享命名空间的模型，说明文件语义给分布式实现带来的要求；初期以基础和类型对照为主。

## 核心问题

- 路径、目录、文件与文件元数据之间是什么关系？
- 文件共享、重命名、锁与缓存如何影响并发访问？
- POSIX 语义与不同网络文件接口的边界如何区分？

## 后续准备展开的主题

- 文件 / 目录、命名空间、权限与元数据操作。
- 文件共享、客户端缓存与一致性；POSIX、NFS、SMB 的语义边界。
- 小文件、目录遍历与海量命名空间的典型问题。
