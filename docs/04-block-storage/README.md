# Block Storage

## 页面定位

理解按块寻址的卷抽象、基本 I/O 语义与责任边界，建立与对象、文件存储的对照；当前保持类型入口，统一访问模型对照见 [Architecture Map](../01-overview/01-storage-models-architecture-map.md)，按需要再扩展，不表示完整专题已完成。

## 核心问题

- 卷、逻辑块地址与读写请求如何定义访问模型？
- 块存储与上层文件系统分别负责哪些语义？
- 写入顺序、持久化、共享访问和快照需要哪些约束？

## 后续准备展开的主题

- 卷与块寻址、覆盖写、对齐和基本 I/O 语义。
- 本地 / 远程块访问，以及与文件系统、数据库的责任边界。
- 快照、克隆与精简置备的概念和取舍。
