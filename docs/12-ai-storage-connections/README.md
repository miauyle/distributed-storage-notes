# AI Storage Connections

## 页面定位

从训练和推理的实际数据需求出发，连接已有的存储语义、缓存、性能与运维知识；保持存储视角，不扩展成通用 AI 平台教程或面试冲刺材料。

## 核心问题

- 数据集读取、检查点与推理缓存具有哪些不同的访问模式？
- 对象存储如何连接文件访问层、数据加载器和 GPU？
- 哪些数据需要持久保护，哪些缓存可以重建或淘汰？
- 如何验证数据供给改善是否减少了计算等待，而不只提高存储吞吐？

## 后续准备展开的主题

- 训练数据集、检查点与模型权重的大小、访问粒度及共享方式。
- 对象存储到训练读取链路：数据格式、文件访问层、缓存、预取与 DataLoader。
- GPU 数据路径：Pinned Memory、内存复制、GDS / Zero-copy 的边界与前置条件。
- RDMA 与 S3 访问路径的关系；区分底层传输、协议语义和具体实现。
- KV Cache 的分层、共享、淘汰与数据生命周期，区分缓存和持久数据。
- 吞吐、尾延迟、GPU 等待、缓存命中与端到端验证。
